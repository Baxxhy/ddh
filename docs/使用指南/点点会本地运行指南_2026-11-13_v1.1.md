# 点点会本地运行指南

**版本：** V1.1  
**日期：** 2026 年 11 月 13 日

点点会第一版采用 React + TypeScript + Vite 前端、FastAPI 后端和 MySQL。当前仓库只完成开发计划的**第一阶段**：首页和场景介绍页从 API 读取三个演示场景。挂号、乘车码、扫码支付的实际练习流程，以及 AI 和语音指导，尚未实现；介绍页会明确显示“练习功能即将开放”。

## 环境要求

- Node.js 20.19+ 或 22.12+，npm。
- Python 3.12（本阶段验证版本）。
- Docker 与 Docker Compose，用于本地 MySQL 8.4；也可自行准备兼容的 MySQL。
- 电脑和手机在同一局域网内，手机浏览器可以访问电脑的 5173 端口。

## 首次准备

以下命令在仓库根目录执行：

```bash
cp .env.example .env
```

编辑 `.env`，设置本地 MySQL 密码，并确保 `DATABASE_URL` 中的密码与 `MYSQL_PASSWORD` 一致。如果密码含有 `@`、`:` 等 URL 特殊字符，需要在 `DATABASE_URL` 中编码。`.env` 已被 Git 忽略，不要提交真实密码。

```bash
docker compose up -d --wait mysql
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.lock
.venv/bin/python -m alembic -c backend/alembic.ini upgrade head
.venv/bin/python -m backend.app.seed
```

迁移创建 `scenario_versions`、`practice_sessions`、`knowledge_chunks` 三张表；初始化命令写入三个版本化演示场景；重复执行不会覆盖已有记录。若使用自行安装的 MySQL，先创建数据库和用户，并将其连接地址写入 `.env`。

## 启动前后端

在仓库根目录打开一个终端启动 FastAPI：

```bash
.venv/bin/python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

再打开另一个终端启动 Vite：

```bash
cd frontend
npm ci
npm run dev
```

电脑浏览器访问 `http://localhost:5173`。手机和电脑连接同一局域网后，在手机浏览器访问 `http://<电脑的局域网 IP>:5173`。Vite 监听 `0.0.0.0` 并将 `/api` 请求转发至电脑本机的 FastAPI `127.0.0.1:8000`，因此手机访问时无需、也不应把 API 地址写成手机的 `localhost`。如果手机打不开页面，先检查电脑实际局域网 IP、网络隔离和 5173 端口的本地防火墙设置。

## 本地检查

```bash
curl http://localhost:8000/api/v1/health
curl http://localhost:8000/api/v1/scenarios
curl http://localhost:5173/api/v1/scenarios
.venv/bin/python -m pytest backend/tests -q
cd frontend && npm run typecheck && npm run lint && npm run build
npx playwright install chromium
npm test
```

场景接口应返回医院挂号、公交乘车码和扫码支付三条演示数据。当前阶段不提供“开始练习”入口，这是按开发计划保留的功能边界。结束本地 MySQL 服务可运行 `docker compose stop mysql`；再次开发时运行 `docker compose up -d mysql`。

## 配置与常见问题

- `.env` 中 `DATABASE_URL` 是 SQLAlchemy 实际使用的完整连接地址。`MYSQL_HOST`、`MYSQL_PORT` 用于说明本地地址，修改数据库地址时同步修改 `DATABASE_URL`。
- `VITE_API_BASE_URL` 默认为 `/api/v1`；`API_PROXY_TARGET` 默认为 `http://127.0.0.1:8000`。手机开发优先保留相对 API 路径。修改配置后重启 Vite。
- `VITE_HOST` 控制前端监听地址。后端可使用 `uvicorn --env-file .env` 之外的显式 `--host`、`--port` 参数；本项目运行命令已明确指定监听地址。
- 若 8000 端口被占用，可将后端改为 `--port 8017`，并将 `API_PROXY_TARGET` 改为 `http://127.0.0.1:8017`。确认不是其他服务占用了该端口。
- `GET /api/v1/scenarios/hospital` 可检查详情。接口成功返回 JSON 数据，错误返回含中文 `detail` 的 JSON，404 表示场景不存在，503 表示数据库暂时不可用。
- 迁移检查命令：`.venv/bin/python -m alembic -c backend/alembic.ini check`。已有旧版表也可升级，保留原场景记录；迁移不提供自动删表降级。
- Playwright 测试需前后端已经运行。自定义前端端口时：`TEST_BASE_URL=http://127.0.0.1:5174 npm test`。Linux 缺少浏览器依赖时运行 `npx playwright install --with-deps chromium`。
