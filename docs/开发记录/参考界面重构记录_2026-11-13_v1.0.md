# 点点会参考界面重构记录

版本：V1.0  
日期：2026-11-13

## 需求及设计依据

项目负责人认为原界面不美观，要求根据所提供截图、31页UI设计zip及index.html学习结构和排版，完全重构界面并优先使用组件库。本轮参考设计中的手机应用导航、服务入口、列表、商户核对、金额键盘及结果页排版。

## 实际改动

- 页面采用居中顶部标题、返回导航和大字开关；去掉每个页面重复的大块品牌栏和任务说明。任务目标在介绍页完整展示，练习页可展开查看。
- 首页采用医院、公交、支付三种颜色的图标与服务卡片；介绍页采用场景图形、居中目标、模拟提示和底部开始操作。
- 医院服务首页改为服务区块与宫格，选择步骤使用Taro UI AtList列表，医院搜索实际筛选服务端选项；保留科室、门诊、时段和核对的独立页面。
- 公交采用出行入口、交通列表、乘车码卡片；使用无有效编码的自绘演示图形，未生成真实二维码。
- 支付采用商户列表、收款方、金额输入和核对页面；AmountEntry提供可操作数字键盘、删除、清空及系统键盘切换，仍提交后端校验。
- 成功页保留后端结果，突出完成状态、金额及选择摘要；异常与空页面统一排版。AtTag继续作为模拟标识，原生按钮、输入及标签维持键盘语义。

参考稿中的医院名称、医生、评级及日期未替换实际演示资料；所有可选择的业务内容仍来自API。AI帮助、语音和未实现的服务入口没有作为可用功能加入。保持React/TypeScript/Vite和5173端口。

## 验证与修复

初次全量回归发现介绍页顶部与主体各有同名标题，造成语义重复。保留顶部唯一标题并将主体场景名称改为普通强调文本，原测试断言保持不变，随后64项浏览器测试通过。53项后端测试通过；类型检查、Lint及构建通过。异常页补齐后再次运行6项首页/场景回归及1项刷新回归，全部通过。

已查看实际运行的首页、任务说明、医疗首页、医院列表和金额键盘截图；截图由真实浏览器生成。详细依据见[重构验证记录](../测试验证/参考界面重构验证_2026-11-13_v1.0.md)。
