# 前端永久端口5200

版本：V1.0  
日期：2026-11-14

项目负责人明确要求将前端永久改为5200，替代原5173要求。已同步修改AGENTS.md、Vite开发与预览配置、端口强制校验、Playwright地址、后端默认CORS与.env.example；本地忽略的.env也同步CORS。新增运行指南V1.6，旧版文件保留为历史。

关闭本项目远程5173进程，前端在双栈5200启动，后端保持8017。实际HTML和代理健康接口返回200；直接后端GET请求确认允许Origin http://localhost:5200。显式指定5173启动时，在监听前被配置拒绝，没有另开旧端口。

验证：5200下Playwright全量64项通过；后端场景测试3项通过，存在既有Starlette/httpx弃用警告；TypeScript类型检查、ESLint、构建和git diff --check通过。当前源码、AGENTS及环境模板没有遗留5173引用。

用户Windows本机的5200转发尚未验证，需要同步SSH本地转发后再访问。服务器端返回200不等于用户电脑的访问链路已经验证。运行指南提供本机5200到远程5200的转发命令。
