# 前端字体与组件规范调整

版本：V1.0  
日期：2026-11-13

项目负责人要求前端只使用5173端口，中文使用系统默认字体或微软雅黑，英文使用Times New Roman，React UI库选用Taro UI for React。

已在AGENTS.md保留端口限制、替换两处shadcn/ui选型要求并增加字体规范。现有公共样式采用Times New Roman、Microsoft YaHei、系统字体的回退顺序，以支持中英文混排。

本次落实规范及公共字体，尚未安装或迁移Taro UI组件；后续组件接入须验证现有React、Vite兼容性和适老化尺寸，不擅自替换构建框架。
